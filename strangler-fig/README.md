Welcome to the Garden Show!

The greenhouse has grown into a legacy monolithic plant show, and every entry is competing for ribbons.

Our goal is use the strangler fig pattern to create a new stable system.

We are a store... I would like to make deals with customers that don't involve how well a plant shows.

As a level 20 Botanist I trust you can handle this quest!

For more information about the strangler fig pattern I recommend the following article by Martin Fowler: https://martinfowler.com/bliki/StranglerFigApplication.html

For more information about the strangler fig plant species, which is dope btw I recommend reading this wiki article: https://en.wikipedia.org/wiki/Strangler_fig

Startup:

./gradlew :legacy-greenhouse:bootRun

open http://localhost:8080/swagger-ui/index.html
