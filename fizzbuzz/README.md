# fizzbuzz

## Pair up.​
​
Use AAA and test naming patterns to satisfy requirements.​


For every multiple of three, return `Fizz`.​

For every multiple of five, return `Buzz`.​

For every multiple of three and five, return `FizzBuzz`.​

For every other number, return the number.​

## Tech

- Java
- Gradle (wrapper included)
- JUnit 5 (Jupiter)

## Usage

```
./gradlew build   # compile and test
./gradlew test    # run tests only
```

Sources go in `src/main/java`, tests in `src/test/java`.
